A single funny one-line excuse an AI agent gives its human for a missed deadline: I missed the deadline because I asked my future self to do it, and he just hallucinated that he did.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22+, stdlib only) validates the line against the gate — one line, 1–200 characters, not only whitespace — and writes it, byte-identically on every run, to `/output/entry.txt`.
